KLAWER HARDWARE STORE WEBSITE

FILES
- index.html: the website homepage
- assets/: site photos, logo, and intro video

PREVIEW LOCALLY
1. Extract the ZIP file (if you received the ZIP).
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. Keep the assets folder beside index.html so photos and video load correctly.

UPLOAD TO YOUR WEB HOST
1. Log in to your hosting control panel (for example, cPanel File Manager).
2. Open the website document root, usually public_html.
3. Upload the contents of this folder, including index.html and the complete assets folder.
4. Visit your domain and test the menu, phone, WhatsApp, directions, photos, and video.
